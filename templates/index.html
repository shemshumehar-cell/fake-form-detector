Strictly Passive & Non-Destructive Analysis

This scanner only reads public HTTP response headers and parses static HTML form structures. It never attempts unauthorized logins, never injects payloads, never executes brute-force attacks, and never submits forms to external websites.

Passive Security Inspection Engine

🔐

HTTPS Transport Check

Verifies whether the target domain enforces TLS encryption and inspects HTTP redirect chains to detect insecure plaintext downgrade risks.

🛡️

HTTP Security Headers

Audits five fundamental browser defense headers: Content-Security-Policy (CSP), Strict-Transport-Security (HSTS), X-Content-Type-Options, Referrer-Policy, and Permissions-Policy.

📋

HTML Form Structure

Parses form methods (GET vs POST), action destinations, mixed-content vulnerabilities, and checks for anti-CSRF token presence.

🔑

Password Transmission

Detects password inputs and evaluates whether authentication forms risk exposing sensitive credentials across unencrypted channels or via HTTP GET.

📁

File Upload Guardrails

Identifies file upload endpoints and supplies vital defense-in-depth guidance covering MIME verification, size limits, and storage isolation.

📊

Transparent 0–100 Score

Generates a visual Security Report Card categorizing findings by severity, explaining why each finding matters, and outlining remediation steps.
